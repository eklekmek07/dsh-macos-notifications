# DSH macOS Notifications

An independent, open-source notification plugin for DeepSeek Harness on macOS.

This repository is being prepared for its first feature pull request. The implementation will provide in-app notification preferences and an attention list, without modifying the signed DSH application.

AI/vibecode disclosure: this project is developed with AI assistance. It is experimental, not an official DeepSeek product, and has no independent security audit.
